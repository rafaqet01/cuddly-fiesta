# Cuddly Fiesta 🎬 San Francisco Film Locations

A data-focused repository featuring a dataset of film and television shooting locations across San Francisco.

## 📂 Dataset Overview

* **File Name:** `Film_Locations_in_San_Francisco_20260921.csv`
* **Description:** Contains records of movies, TV shows, and commercial productions filmed in San Francisco, including details such as:
  * Title and Release Year
  * Specific Locations / Neighborhoods
  * Director, Writer, and Cast information
  * Fun facts or production notes (where available)
